# Shipping Settings Guide

Date modified: 2023-04-14

Shipping settings can be found in the Admin section of the Web Application. [Shipping Settings](/admin/shipping-setting). You must be logged in before you can access it.

## Flow

When you open the page, you will see some buttons, like Add Setting, Products, and Categories. If you want to create a new shipping setting, click the Add Setting button.

A form will pop up with some fields like Label, Own Country, Own State, Own City, Other Country, Other State, and Other City. You can choose what shipping options you want by ticking the Activate checkbox. Then, fill in the corresponding fields for Shipping value, Express Post, Registered Post, and Insurance.

When you're done, click the confirm button on the left. Your shipping settings will apply to the total of all the products you are buying.

## Note

As of this writing, a shipping setting can be added or removed, but cannot be directly edited. If you want to make changes, you need to remove the existing setting and create a new one by typing in the edited values that you wish to modify.

## Summary

Shipping settings are a feature in the admin section of the web application that allows you to set up different shipping options for your products. You can create a new shipping setting by filling out a form with fields like Label, Own Country, Own State, Own City, Other Country, Other State, and Other City. You can choose what shipping options you want by ticking the Activate checkbox and filling in the corresponding fields for Shipping value, Express Post, Registered Post, and Insurance. Once you confirm your settings, they will apply to the total of all the products you are buying. If you want to make changes to an existing setting, you need to remove it and create a new one with the edited values.
