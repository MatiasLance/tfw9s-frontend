# 1. Edit shipping details, Shipping Setting Issues

Date: 2023-04-14

## Status
COMPLETED

## Context
"Just need advise on a few things regarding Shipping which seem to be causing a problem on the website;

Q1: when I set-up a setting for shipping - is there a way of being able to EDIT the details, and even the name after I have created it?

Q2: when I do a mock order to test, multiple items render a huge shipping cost because it combines the individual item's shipping cost

Im already getting emails from potential clients getting confused, please help."

In other words (like a high schooler can understand):
When you buy things online, sometimes the store charges you for shipping the things to your house. When you do a pretend order to see how much the shipping costs, it might look like the shipping cost is really high if you buy a lot of things at once. This is because the store adds up the shipping cost for each individual thing, which makes the total cost look bigger than if you bought all the things together and shipped them at the same time. It's like if you went to the store and bought five separate items, and then the cashier charged you a separate fee for each item instead of giving you one total price for all of them.

## Decision

"when I set-up a setting for shipping - is there a way of being able to EDIT the details, and even the name after I have created it?"
>
1. At the moment, you can only ADD and REMOVE a shipping. There’s no EDIT function yet. However, it will take some time — it’s another workaround feature. No worries, it’s a work in progress. If you wish to edit then you have to remove and add it again with your edited setting. 

"when I do a mock order to test, multiple items render a huge shipping cost because it combines the individual item's shipping cost"
>
2. When you do a mock order to test your shipping settings, the system may combine the individual shipping costs for each item in the order, resulting in a higher overall shipping cost. This is because the system calculates the shipping based on the weight, size, or other factors for each individual item, and then adds those costs together. This may not reflect the actual shipping cost if the items were shipped together, as the combined weight or size may be different.

"More to the point - why is shipping always coming up as $75.00? Please check my settings and advise where I am going wrong."

3. Checking on it. As far as I remember, I assume this is a backend query issue where it fetches the recently added shipping setting id instead of fetching the selected shipping setting id of a product
